# P8: Sticky navbar and card overlay using CSS positioning

## Aim
Make a navigation bar stay at the top and place text over a card using CSS positioning.

## CSS concepts
- `position: sticky` keeps the navigation near the top while scrolling.
- `position: relative` gives the card a positioning reference.
- `position: absolute` places the text over the card.

## Files
- `index.html` contains the navigation and cards.
- `style.css` contains the positioning rules.

## What I learned
Positioning helps place elements where they are needed without changing the HTML order.
