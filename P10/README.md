# P10: Portfolio header and footer with advanced Flexbox

## Aim
Create a portfolio header and footer using Flexbox.

## CSS concepts
I used `justify-content`, `align-items`, `gap`, `flex-wrap` and a media query to arrange the header and footer content.

## Files
- `index.html` contains the header, main content and footer.
- `style.css` contains the Flexbox layout.

## What I learned
Flexbox makes it easier to align items and change their arrangement when the screen becomes narrow.
