# P4: GitHub README and version tags

## Aim
Write a README and learn how to mark a version with a Git tag.

## A README can include
- Project name and a short description
- Files included in the project
- How to open or run it
- Technologies used
- Author

## Commands
```bash
git add README.md
git commit -m "Add project README"
git tag v1.0
git push origin main
git push origin v1.0
```

## What I learned
A README explains the project to visitors. A tag such as v1.0 marks a particular version of the project.
