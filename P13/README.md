# P13: Choosing between Flexbox and Grid for a shared layout

## Aim
Use Flexbox and Grid together in one page and understand when each is useful.

## In this page
- Flexbox is used for the header and navigation because the items are arranged in one direction.
- Grid is used for the project area because it needs rows and columns.
- Shared CSS variables keep the colours and spacing consistent.

## Files
- `index.html` contains the shared page structure.
- `style.css` contains both layout systems.

## What I learned
Flexbox and Grid are not competitors. I can choose Flexbox for one-dimensional alignment and Grid for a two-dimensional layout.
