# P2: Portfolio repo with an initial commit

## Aim
Create a small portfolio, initialise Git and save its first version.

## Steps
1. Create a project folder and add the HTML and CSS files.
2. Run `git init` inside the folder.
3. Check the files with `git status`.
4. Stage the files and make the first commit.
5. Create an empty repository on GitHub, connect it as origin and push main.

## Commands
```bash
git init
git status
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

The repository URL is added on my own computer during setup.

## What I learned
Git keeps track of project changes, and GitHub stores the repository online.
