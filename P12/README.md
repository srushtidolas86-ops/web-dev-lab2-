# P12: Portfolio projects grid with advanced CSS Grid

## Aim
Display portfolio project cards using CSS Grid.

## CSS concepts
I used `repeat()`, `minmax()` and `auto-fit` to make a grid that adjusts to the available width. Each card has its own space and the grid changes on smaller screens.

## Files
- `index.html` contains the project cards.
- `style.css` contains the Grid rules.

## What I learned
CSS Grid helps create a layout with more control over both rows and columns.
