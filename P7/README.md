# P7: Design tokens and typography system in CSS

## Aim
Use CSS variables for common colours, spacing and typography.

## What I used
The stylesheet has variables inside `:root`. I reused them for the page background, text, accent colour and spacing.

## Files
- `index.html` shows the typography and design examples.
- `style.css` stores the design tokens and styles.

## What I learned
If I want to change a common colour or spacing value, I can update the variable instead of searching through the whole stylesheet.
