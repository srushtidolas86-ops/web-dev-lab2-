# P9: Responsive navbar and card grid using Flexbox

## Aim
Make a navigation bar and a group of cards adjust to different screen sizes using Flexbox.

## CSS concepts
- `display: flex` arranges the items.
- `flex-wrap: wrap` lets items move to the next line.
- A media query adjusts spacing on smaller screens.

## Files
- `index.html` contains the navigation and cards.
- `style.css` contains the Flexbox and responsive rules.

## What I learned
Flexbox is useful for arranging items in a row or column. Wrapping helps the layout fit smaller screens.
