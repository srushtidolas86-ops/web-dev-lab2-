# P5: Semantic bio page

## Aim
Create a simple biography page using semantic HTML elements.

## HTML elements used
- `header` for the page heading
- `main` for the main content
- `section` for related information
- `footer` for the closing line

## Files
- `index.html` contains the page structure.
- `style.css` contains the design.

## What I learned
Semantic elements make the page structure easier to understand. The CSS is linked externally instead of being written inside the HTML.
