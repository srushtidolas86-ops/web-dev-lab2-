# P1: Project folder and terminal navigation

## Aim
Create a project folder and learn to move between folders using the terminal.

## Steps
1. Open Terminal.
2. Move to the place where I keep my college work.
3. Create a folder using `mkdir web-dev-lab`.
4. Enter it using `cd web-dev-lab`.
5. Check the current location with `pwd` and list files with `ls`.
6. Create a file using `touch index.html`.

## Commands
```bash
pwd
ls
mkdir web-dev-lab
cd web-dev-lab
touch index.html
```

## What I learned
The terminal helps me create folders, move around my project and check files.
