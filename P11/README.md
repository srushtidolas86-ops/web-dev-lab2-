# P11: Newspaper-style three-column layout with CSS Grid

## Aim
Create a simple newspaper-style page with three columns using CSS Grid.

## CSS concepts
- `display: grid` creates the grid.
- `grid-template-columns` sets the columns.
- `gap` adds space between the articles.
- A media query changes the layout on smaller screens.

## Files
- `index.html` contains the newspaper heading and article cards.
- `style.css` contains the Grid layout.

## What I learned
Grid is useful when I need to arrange content in rows and columns.
